> Channel：GA
> Source freeze：TASK-0075 sealed Result Commit and `v0.1.0`

## What is included

- `moye` umbrella npm package with `moye/core`, `moye/client`, `moye/plugin-sdk`, CLI and Project Schema v1;
- `.moye/project.yaml`, `init`, `doctor`, `project validate`, `task start/status/watch/open`;
- five blocking workflow roles plus non-blocking Observer/Knowledge, real Codex/Claude Session evidence, Trusted Runner, Git checkpoint/merge, Closure and Archive;
- configurable Documentation Policy: `none | conventional | moye-doc-graph | custom`;
- Service image, Restate Compose, persistent local volumes, health/readiness, backup/restore, upgrade and rollback procedures;
- Node/TypeScript, Python and Minimal Git examples plus a real external-project product matrix covering Happy, Repair, Reconcile, failed Archive and cross-version recovery.

## Install and verify

When the npm receipt is `CONFIRMED`:

```bash
npm install --save-dev moye@0.1.0
npx moye --help
npx moye init --dir . --project-id my-project
npx moye doctor --file .moye/project.yaml
```

When npm publication is blocked, use the checksum-verified `moye-0.1.0.tgz` attached to the GitHub Release or produced by the local GA pipeline. Migration and rollback procedures are in the [Framework Migration Runbook](../runbooks/framework-migration.md).

## Security and known limitations

Read [SECURITY.md](../../../../SECURITY.md) before exposing a Service or enabling Transcript capture. This release does not provide remote SCM/PR automation, multi-node leases and complete fencing, Auth/RBAC, multi-tenancy, hardened untrusted-code sandboxing, managed secrets, remote Artifact storage, HA/SLO/alerting or disaster recovery. These omissions are not covered by the local product evidence.
