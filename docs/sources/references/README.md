# References：外部参考资料

References 登记外部文档、论文、仓库、标准和其他资料来源。Reference 只说明“信息来自哪里以及适用于什么范围”，不自动代表信息正确、当前或适合 Moye。

Reference 与 Research 的边界：

- Reference 是外部来源及必要摘要；
- Research 是 Moye 基于多个 Reference、实验和代码检查形成的内部分析；
- Reference 和 Research 都不能替代 Accepted ADR 或当前 Architecture。

登记资料时至少记录来源类型、访问日期、版本或更新时间、适用主题和已知限制。当前尚无独立 Reference 文档；现有调研中的链接后续可以按需要提升为稳定 Reference 节点。
