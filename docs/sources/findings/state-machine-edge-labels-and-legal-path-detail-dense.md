# 状态机边标签与合法路径详情可读性不足

> 文档类型：Finding
> 状态：Confirmed
> 发现日期：2026-08-22
> 影响范围：Task Graph、节点 Inspector、合法状态转换

## 观察

在真实 Coding Task `TASK-LIVE-ROLE-STREAM-2-20260822` 中打开状态机总览时，未经过的合法边也直接在 SVG 画布上显示完整说明。缩放到适配视图后，这些说明成为无法阅读的小字并与路径互相干扰。

选择 `IMPLEMENT` 节点并展开“查看合法进入与离开路径”后，内容仍使用旧的双卡片网格；来源、目标、本次是否经过和转换说明缺少稳定的扫读顺序，窄侧栏底部尤其拥挤。

## 影响

- 总览画布同时承担拓扑、运行路径与完整边说明，视觉噪声过高；
- 未展开的信息以小字泄漏到画布，用户无法判断它是否可操作；
- 合法路径详情没有清楚区分“代码允许”与“本次 Event 已证明经过”；
- 长状态名和说明在侧栏与移动端容易换行成碎片。

## 边界

修复只改变只读投影的展示层级，不删除状态机 Definition 中的合法边，不修改 History、Workflow 或 Event。画布负责总览与实际路径点亮；完整合法转换在选中节点后按需展开。
