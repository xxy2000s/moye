# Research：内部分析

Research 记录基于 Reference、实验和代码检查形成的内部比较、分析和推论。Research 可以支持 ADR，但本身不代表架构决定。

## 当前文档

- [Durable Workflow 与可观测方案调研](./durable-workflow-and-observability-options.md)
- [Restate TypeScript PoC 实现基线](./restate-typescript-implementation-baseline.md)

## 规则

- 标注调研日期；
- 优先引用官方和一手 Reference；
- 区分“来源事实”和“项目推论”；
- 记录未选择方案，而不是只保留胜出方案；
- 实验需要记录环境、版本、步骤和原始结果；
- 形成正式选择时创建 ADR；
- 结论过期时保留历史并标注状态，不静默重写。

单个外部链接或资料摘要应进入 [References](../references/README.md)，不是 Research。
