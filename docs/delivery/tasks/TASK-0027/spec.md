# TASK-0027 Spec：状态机转换的渐进披露与可扫描详情

> 状态：Approved for bootstrap execution
> Spec Revision：1
> Backlog：BL-0028

## 目标

让状态机画布优先回答“有哪些状态、实际走了哪条路”，并让节点详情清楚回答“代码允许从哪里来、可以去哪里、本次是否真的经过”。

## Requirements

### REQ-0027-01：画布边标签降噪

- 未经过的合法边保留路径、方向和可访问名称，但默认不在画布铺陈完整说明；
- 实际经过的边保留清晰、紧凑的 sequence 标记；
- 不通过极小字号承载必须信息，完整说明仍可在节点合法路径详情查看。

### REQ-0027-02：合法路径详情重构

- 展开入口直接显示进入/离开数量；
- 进入和离开按方向分组为扁平列表，每行显示来源 → 目标、转换类型与人类说明；
- 明确标出 `本次经过 · #sequence` 或 `合法但未发生`，不能只靠颜色区分；
- 无进入或离开路径时显示明确空状态。

### REQ-0027-03：响应式与回归

- 长状态名和说明在桌面 Inspector 与移动 Bottom Sheet 中可读且不横向溢出；
- 节点选择、关闭、Esc 回焦、缩放和完整 Events Dialog 行为保持不变；
- 使用真实 Task Projection 验收，不用 Mock/Fake 数据冒充页面结果。

## 非目标

- 不改变 Workflow、状态机 Definition/History 或事件内容；
- 不新增图编辑能力；
- 不改变业务状态或 Task Runtime API。
